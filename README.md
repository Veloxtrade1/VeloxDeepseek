# Velox Trading Platform – Complete

## Setup
1. Install Node.js, MongoDB
2. `npm install`
3. Create `.env` with your keys
4. `npm start`
5. Open http://localhost:5000

## Admin Access
- Admin key: `admin123`
- Admin panel: `/admin/index`

- Live market data (Twelve Data WebSocket)
- Demo & Real money modes
- All order types (market, limit, stop, trailing)
- 2FA, email verification, password reset
